ONLINE DEPLOYMENT QUICK GUIDE

1) Extract this ZIP.
2) Upload the CONTENTS of the crop_doctor folder (not the ZIP) to a GitHub repository.
3) Open https://share.streamlit.io/ and connect GitHub.
4) Create app -> choose your repository -> branch main -> app.py.
5) Advanced settings -> Python 3.12 -> Deploy.
6) Use the new https://....streamlit.app URL on phones/other computers.

See DEPLOY_TO_CLOUD.md for full details and optional API-key configuration.
